# Efficient execution

- Search with `rg` and batch independent reads/checks. Delegate independent areas when useful; assign disjoint files because all agents share the checkout.
- Read the relevant map/skill instead of loading every dossier or the full blueprint. Exclude historical copies and generated output from broad searches.
- Reuse facts already read, but re-read when concurrent edits, stale assumptions, errors, or verification require fresh evidence. A cache is not proof of current source.
- Make coherent edits and run checks relevant to their behavior. Fix legitimate failures at the responsible layer; do not expand into unrelated cleanup.
- Use bounded commands and foreground optional watchers. Do not start duplicate Flutter jobs or permanent background processes from lifecycle hooks.
- Finish required tests and the authorized Git lifecycle, then stop. Report unresolved failures truthfully; avoid cosmetic loops after acceptance is satisfied.
