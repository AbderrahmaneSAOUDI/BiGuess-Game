# Strict Scope Fidelity & Explicit Instruction Compliance

## 1. Zero Unprompted Additions
- **Do Exactly What Is Commanded**: Only implement the specific changes, elements, or logic explicitly requested by the user. Do not add unrequested features, extra boilerplate, or speculative code.
- **Never Add Unrequested Content**: NEVER add extra text, headings, paragraphs, descriptions, placeholder copy, or marketing text unless explicitly requested.
- **Never Add Unrequested UI Elements**: NEVER add unrequested UI elements (such as extra buttons, icons, modals, cards, badges, banners, navigation links, forms, or sidebars) that the user did not instruct you to add.
- **Preserve Existing Elements & Copy**: Do not modify, reword, replace, or remove existing content or elements unless specifically instructed to do so.

## 2. Mandatory Prior Approval for Improvements & Additions
- **Ask Before Implementing**: If you notice an opportunity for improvement, enhancement, optimization, or a useful addition, **DO NOT** implement it automatically or proactively.
- **Prompt the User First**: Ask the user explicitly in your response (e.g. *"Would you like me to add [X] to improve [Y]?"*) and wait for their explicit permission before adding or changing anything.
